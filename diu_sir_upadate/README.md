# DIU supervisor progress update

Self-contained HTML report for capstone supervision (literature alignment, completed data work, model-training roadmap).

## View

Open **`index.html`** in Chrome, Edge, or Firefox (double-click or drag into the browser).

## Print to PDF

Browser menu → **Print** → **Save as PDF** (A4). Styles include a print layout.

## Regenerate content

Edit `index.html` when pipeline or model milestones change. Source material: `project-plan/data-engineering.md`, `README.md`, and `papers/`.

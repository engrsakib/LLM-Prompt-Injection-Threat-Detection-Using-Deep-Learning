1. Executive summary

The thesis targets multi-class prompt injection detection (seven intent classes, severity metadata, technique-aware evaluation) using the Neuralchemy Threat Matrix dataset and comparative deep learning. The data engineering pipeline (Phases 1–3) is implemented and tested: ingestion with versioned snapshots, obfuscation-preserving cleaning, deduplication, validation, enrichment, technique subsets, adversarial paraphrase augmentation, leakage auditing, reproducibility documentation, and Kaggle packaging. This layer is suitable for IEEE-style reproducibility reporting with transparent limitations.

Update 2026-11-07. The leakage problem has been remediated: Phase 3.5 performs a group-aware re-split of the local snapshot (duplicate / template / near-duplicate families never cross splits), producing the frozen v1_leakfree splits with 22,093 / 2,780 / 2,802 rows and 0 cross-split overlaps (raw, exact, near, family). The 16-model study scaffolding is implemented and unit-tested (42 tests): shared classifier interface, registry with verified checkpoints (SecureBERT identifier corrected; Llama-3.1-8B blocked as gated), a resumable trainer and sweep, full metric suite, per-example prediction exports, 17 figure types and a thin Kaggle notebook. Only CPU smoke runs (TextCNN, DistilBERT on 300-row subsets) have been executed; no production training or thesis-level results exist yet. The next step is GPU training on Kaggle.
